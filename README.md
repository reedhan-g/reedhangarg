# Reedhan Garg — Portfolio

Hi, I'm Reedhan, a Computer Science and Engineering student at Delhi Technological University in New Delhi. I'm curious about how things work and enjoy learning by building. My interests include web development, cybersecurity, competitive programming, and artificial intelligence and machine learning.

This portfolio is a small desktop on the web. Open a window to explore my work, learn more about me, or get in touch.

## Inside the desktop

- **Selected Works** — a look at projects including Last Hex, Auth Log Parser and IGTS DTU.
- **About and Résumé** — an introduction to my interests and background.
- **Terminal** — a simulated terminal with commands to explore the portfolio; type `help` to get started.
- **Desktop Radio** — optional lo-fi and ambient music, with credits in [MUSIC-CREDITS.md](MUSIC-CREDITS.md).

The desktop also includes draggable windows, three themes, a game and other small interactions.
